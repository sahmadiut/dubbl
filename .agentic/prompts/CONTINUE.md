# Portable one-task prompt

Read `.agentic/START_HERE.md`. Continue exactly one task selected by `.agentic/agent.py context`, resuming active work first. Inspect code and dependency evidence, implement only the bounded task, run meaningful checks, update handoff/evidence/registries and validate task state. Obtain only genuinely required external decisions or reviews; never impersonate them. Stop after the task or a precise blocker and report the next action.
