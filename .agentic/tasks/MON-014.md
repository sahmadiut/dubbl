# MON-014 ? Adopt exact contracts at core accounting boundaries

## Objective and implementation scope

Journal entries, receivables, payables, payments/credits, expenses, banking, tax configuration and organization/contact thresholds in REST and MCP. Add lossless minor-unit/rate aliases and explicit supported ranges before mutation, retain period locks/audit/idempotency and inventory every operation. Inspect actual units; split further by verified domain if too broad. Number domain cutover remains MON-007.

## Inputs

Parent [MON-012](MON-012.md), MON-011 evidence, ADR-006, [migration](../sources/SOURCE.md#database-and-currency-migration) and [API compatibility](../sources/SOURCE.md#api-backward-compatibility), MONEY_MANIFEST and actual source.

## Acceptance criteria

- [ ] Every boundary in the adopted slice has documented inputs, outputs, units, exact aliases and supported business ranges.
- [ ] Real REST/MCP operation fixtures cover old and exact clients, authorization and organization isolation.
- [ ] Invalid or unsupported aliases fail before mutation; adopted responses preserve numeric compatibility without bigint crashes or silent precision/unit loss.

## Verification

Run positive/negative operation fixtures, typecheck and lint; record actual results/limits. No builds or unrequested dev server.
