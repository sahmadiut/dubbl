## شروع سریع

<Steps>
  <Step>
    ### کلون و نصب وابستگی‌ها

    ```bash
    git clone https://github.com/dubbl-org/dubbl.git
    cd dubbl && pnpm install
    ```
  </Step>
  <Step>
    ### پیکربندی متغیرهای محیطی

    ```bash
    cp .env.example .env
    # فایل .env را با اطلاعات دیتابیس و کلیدهای امنیتی ویرایش کنید
    ```
  </Step>
  <Step>
    ### راه‌اندازی پایگاه داده

    ```bash
    pnpm db:push
    pnpm db:seed  # اطلاعات نمایشی تستی (اختیاری)
    ```
  </Step>
  <Step>
    ### اجرای برنامه

    ```bash
    pnpm dev
    ```

    آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.
  </Step>
</Steps>
