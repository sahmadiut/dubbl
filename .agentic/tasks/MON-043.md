# MON-043 - Adopt exact sales receipt contracts

## Objective and implementation scope

Sales receipt REST/MCP CRUD/post/void, line pricing/tax/discount and inventory/bank/deposit dimensions; qualify monetary ranges, tenant scope, locks and atomic posting/reversal.

## Inputs

Parent [MON-019](MON-019.md), MON-011 evidence, ADR-006, MONEY_MANIFEST and actual source. Requirements: [migration](../sources/SOURCE.md#database-and-currency-migration) and [API compatibility](../sources/SOURCE.md#api-backward-compatibility).

## Acceptance criteria

- [x] Every boundary in this slice has documented inputs, outputs, units, exact aliases and supported ranges.
- [x] Actual REST/MCP fixtures cover legacy and exact clients, authorization and organization isolation.
- [x] Invalid or unsupported values fail before mutation; responses preserve numeric compatibility without bigint crashes or silent precision/unit loss.

## Verification

Run meaningful operation fixtures, typecheck and lint. No builds or unrequested dev server.

## Handoff

Implemented shared `lib/api/sales-receipt-wire.ts` and `sales-receipts.ts`, four
REST route files and seven registered MCP tools, including new draft update/delete
parity. Both transports retain decimal-major numeric prices, add exact major/minor
aliases and use bigint extended-price/discount/tax/FX arithmetic within the safe
number coexistence range. Organization/receipt locks and transactions cover
numbering/header/lines, bank links/control accounts, cash/revenue/tax recognition,
average/FIFO warehouse stock and saved FX/COGS/cost reversals. Unsupported or
corrupt history rejects without committed effects.

Actual authenticated REST/registered SDK fixtures on disposable migrated
PostgreSQL cover legacy/exact/dual input, roles/two tenants, all dimensions,
locks, maximum/unsafe money, FX/stock history, concurrency and injected rollback.
130 unit tests and three receipt/credit/invoice-lifecycle workers passed; final
receipt worker, targeted six tests/lint, typecheck and inventory verification
passed after self-review hardening. Full lint: 159 existing warnings, no errors.
See registries/SALES_RECEIPT_WIRE_CONTRACTS.md, evidence/MON-043-attempt-1.md and
evidence/MON-043-review-1.md for contracts, real results and limitations.

No bounded-slice blocker. Full-int64 business cutover, external writer/config
coordination, historical unlinked stock/base-currency policy, UI/PDF/provider,
combined receivable and financial/IRR release qualification retain their gates.
No schema, rollout flag, application DB or deployment change. User authorized
commit/push after task completion. Next task: MON-044, recurring invoice contracts.
