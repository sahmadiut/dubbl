- PAR-001/PAR-002 must reuse the supplier debit-note/AP-credit implementation where correct; dedicated vendor-credit naming in the plan is not proof of missing accounting. PAR-003 owns linked supplier-credit refunds; PAR-004 owns customer credit refunds and payment/receipt lifecycle gaps.

Public transfer schemas are generic numeric quantities and contain incomplete entry typing, so no undocumented partial-receipt guarantee is attributed to Bigcapital.
- DATA-004/MON-007 must close period-lock coverage on match-created payments, qualify state transitions/rules/matches and preserve existing journals. PAR-007/QA-002 owns payment-link role/MCP/security coverage.
- DATA-001/DATA-003 owns generic resource metadata and saved-view/bulk gaps; DATA-002 owns exact/safe exports. PAR-008 compares report formulas/fixtures rather than counts.
- AUD-005 retains genuine owner decisions for optional branches, provider access, SaaS, conveniences, toman and statutory scope. No optional task has been skipped by this audit.
- AUD-002 remains the runtime-baseline blocker: an explicit dev-start request is still required. Docker remains omitted under DEC-002. Source-audit completion does not satisfy DB/browser/accounting/native-language/IRR release gates.
