قالب‌های اسناد نحوه چیدمان و ظاهر فاکتورهای فروش، پیش‌فاکتورها و سایر خروجی‌های PDF شما را تعیین می‌کنند. برای مدیریت آن‌ها به **تنظیمات > قالب‌ها** بروید.

## ساخت یک قالب جدید

۱. روی **قالب جدید** کلیک کنید
۲. یک نام وارد کرده و نوع سند را انتخاب نمایید
۳. تنظیمات ظاهری و محتوایی را مشخص کنید
۴. روی **ایجاد** کلیک کنید

می‌توانید برای هر نوع سند، یک قالب را به عنوان **پیش‌فرض** تعیین نمایید تا خروجی‌های PDF به صورت خودکار با آن قالب تولید شوند.

## تنظیمات قالب

| فیلد | شرح |
|---|---|
| نام | برچسب شناسه این قالب (مانند «فاکتور رسمی») |
| نوع | فاکتور، پیش‌فاکتور، رسید دریافت، فیش حقوقی یا سفارش خرید |
| رنگ تأکیدی (Accent Color) | رنگ نوار بالایی و عناصر شاخص در سند PDF |
| آدرس لوگو | پیوند فایل تصویری نشان‌واره شما |
| نمایش تفکیک مالیات | نمایش یا عدم نمایش جزئیات مالیات در بخش جمع نهایی |
| نمایش شرایط تسویه | درج تاریخ سررسید و مهلت پرداخت زیر جمع نهایی |
| تعیین به عنوان پیش‌فرض | استفاده خودکار از این قالب برای نوع سند مشخص‌شده |

## فیلدهای متنی و متغیرهای پویا

این بخش‌ها امکان افزودن اطلاعات سفارشی را فراهم می‌آورند و از **متغیرهای قالب** پشتیبانی می‌کنند.

### اطلاعات حساب بانکی
شماره شبا و اطلاعات بانکی جهت واریز وجه توسط خریدار:

```
شماره شبا: IR000000000000000000000000
شماره حساب: 123-456-789
بانک: بانک ملت - شعبه مرکزی
```

### دستورالعمل‌های پرداخت
توضیحات و شرایط تسویه برای مشتری:

```
لطفاً هنگام پرداخت، شماره فاکتور {{invoiceNumber}} را در شرح واریز درج فرمایید.
```

### توضیحات و یادداشت‌ها
متن‌های ثابت درج‌شده در انتهای سند:

```
با تشکر از همکاری شما. تأخیر در پرداخت مشمول جریمه دیرکرد قانونی خواهد بود.
```

## متغیرهای قالب

می‌توانید از متغیرهای زیر در متون استفاده کنید تا به صورت پویا با اطلاعات واقعی جایگزین شوند:

| متغیر | شرح |
|---|---|
| `{{orgName}}` | نام سازمان شما |
| `{{orgAddress}}` | نشانی سازمان |
| `{{orgTaxId}}` | کد اقتصادی / شناسه مالیاتی سازمان |
| `{{orgPhone}}` | تلفن سازمان |
| `{{orgEmail}}` | ایمیل سازمان |
| `{{invoiceNumber}}` | شماره فاکتور (مانند INV-00001) |
| `{{issueDate}}` | تاریخ صدور |
| `{{dueDate}}` | تاریخ سررسید |
| `{{contactName}}` | نام خریدار یا مشتری |
| `{{contactEmail}}` | ایمیل طرف حساب |
| `{{contactAddress}}` | نشانی خریدار |
| `{{contactTaxNumber}}` | شناسه ملی یا کد اقتصادی خریدار |
| `{{subtotal}}` | جمع کل قبل از تخفیف و مالیات |
| `{{taxTotal}}` | مجموع مبلغ مالیات |
| `{{total}}` | مبلغ کل نهایی قابل پرداخت |
| `{{currency}}` | نماد یا کد ارز |

## پیش‌نمایش و دریافت نمونه

از منوی کنار هر قالب، روی گزینه **پیش‌نمایش** کلیک کنید تا نمای HTML آن را ببینید. همچنین گزینه **دانلود نمونه PDF** خروجی واقعی چاپ را در اختیارتان می‌گذارد.
