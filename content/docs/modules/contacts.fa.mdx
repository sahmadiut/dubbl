مخاطبین نشان‌دهنده اشخاص حقیقی یا شرکت‌های حقوقی هستند که با آن‌ها دادوستد مالی دارید.

## انواع طرف حساب

- **مشتری (Customer)** — خریداران کالا یا خدمات شما (در فاکتورها و پیش‌فاکتورها ظاهر می‌شوند)
- **تأمین‌کننده (Supplier)** — فروشندگان کالا و خدمات به شما (در قبوض خرید و سفارش‌ها ظاهر می‌شوند)
- **هر دو (Both)** — طرف‌هایی که هم خریدار هستند و هم فروشنده

## فیلدهای اطلاعاتی مخاطب

| فیلد | شرح |
|---|---|
| نام | نام شخص یا نام رسمی شرکت |
| ایمیل | نشانی ایمیل اصلی جهت مکاتبات و ارسال فاکتورها |
| تلفن | شماره تماس ثابت یا همراه |
| نوع | مشتری، تأمین‌کننده یا هر دو |
| شناسه ملی / کد اقتصادی | کد ملی، شناسه اقتصادی، شماره VAT یا ABN |
| مهلت پرداخت (شرایط تسویه) | تعداد روزهای پیش‌فرض تا سررسید پرداخت |
| ارز پیش‌فرض | ارز پیش‌فرض برای صدور فاکتورها و تراکنش‌های این مخاطب |
| نشانی‌ها | نشانی صورت‌حساب و نشانی ارسال کالا |
| یادداشت‌ها | توضیحات و یادداشت‌های داخلی سازمانی |

## کاربرد مخاطبین در بخش‌های مختلف

- **فاکتورهای فروش** — انتخاب مشتری هنگام صدور فاکتور
- **پیش‌فاکتورها** — تنظیم و ارسال پیش‌فاکتور
- **قبوض خرید** — ثبت فاکتورهای دریافتی از تأمین‌کننده
- **سفارش‌های خرید (PO)** — ثبت سفارش رسمی به تأمین‌کننده
- **پروژه‌ها** — انتساب پروژه‌ها به کارفرمایان و مشتریان مربوطه

## جستجو و دسته‌بندی

فهرست مخاطبین از قابلیت‌های زیر پشتیبانی می‌کند:
- **جستجوی پیشرفته** بر اساس نام، شرکت یا آدرس ایمیل
- **تب‌های تفکیک‌شده** (همه، مشتریان، تأمین‌کنندگان)
- **صفحه‌بندی روان** برای مدیریت تعداد بالای مخاطبین
