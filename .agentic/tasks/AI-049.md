## Acceptance criteria

- [x] Provide trusted-worker-only approval consumption bound to the exact current batch, decision, selected item, arguments, resources, policies, actor, organization, expiry and current lease. No public/model dispatch capability or domain effect is introduced.

## Handoff

Implemented trusted-only exact approval consumption and fenced finite receipts,
scoped generated metadata storage and real REST/MCP decision-to-SQL qualification.
One concurrent consumer receives original validated arguments; replay only returns
an existing receipt. Confirmed consumed prerequisite receipts are required; stale,
revoked, expired, edited, cancelled, failed and uncertain work fails closed.
Fresh-process recovery cannot replay or overwrite a lost handoff. See
[contract](../docs/AI_ACTION_CONSUMPTION.md) and
[evidence](../evidence/AI-049-attempt-1.md). Focused journey and eight existing
regression/migration cases passed; typecheck, lint, capability/coverage, legacy
money and controller checks passed. Money inventory remains exactly its existing
1447-error baseline. AI-050 owns actual serialized domain effect boundaries and
reconciliation; AI-051 owns explicit REST/MCP resume/worker integration. AI-044
and AI-008 remain open. No push, domain execution, deployment or activation.
