# MON-006 — Evolve API and serialization compatibility

## Objective and implementation scope

Add exact string money/rate representations to the real API and MCP boundaries. Preserve documented v1 semantics for safe numeric legacy fields, reject unrepresentable legacy requests and document deprecation.

- Requirements: [Markdown implementation plan](../sources/SOURCE.md), sections [`database-and-currency-migration`](../sources/SOURCE.md#database-and-currency-migration), [`api-backward-compatibility`](../sources/SOURCE.md#api-backward-compatibility). See [coverage map](../sources/PLAN_COVERAGE.md).

- Dependency task evidence; plan assertions alone do not prove implementation.

## Acceptance criteria

- [ ] No bigint JSON serialization crash.
- [ ] Old supported clients and new exact-string clients pass contract fixtures.
- [ ] Large values cannot silently truncate or change units.
