کلیدهای API به برنامه‌های خارجی اجازه می‌دهند تا از طریق REST API با سازمان dubbl شما تعامل داشته باشند. به مسیر **Settings > API Keys** بروید.

## ایجاد کلید API

۱. روی **New API Key** کلیک کنید
۲. یک نام توصیفی وارد کنید (به عنوان مثال، "Zapier Integration")
۳. کلید فقط یک‌بار نمایش داده می‌شود - آن را کپی کرده و به صورت امن ذخیره کنید
۴. این کلید پس از ایجاد دیگر قابل مشاهده نخواهد بود

## مدیریت کلیدها

| فیلد | توضیحات |
|---|---|
| Name | برچسب توصیفی برای کلید |
| Created | زمان ایجاد کلید |
| Last Used | آخرین زمان استفاده از کلید |
| Status | فعال (Active) یا ابطال‌شده (Revoked) |

## ابطال یک کلید

اگر کلیدی لو رفته است یا دیگر به آن نیازی ندارید:

۱. کلید مورد نظر را در لیست پیدا کنید
۲. روی **Revoke** کلیک کنید
۳. کلید بلافاصله غیرفعال می‌شود

## بهترین روش‌های امنیتی

- برای هر یکپارچه‌سازی، از کلیدهای مجزا استفاده کنید
- کلیدهایی را که دیگر استفاده نمی‌شوند باطل کنید
- هرگز کلیدها را در مخازن عمومی (public repositories) یا گزارش‌ها (logs) به اشتراک نگذارید
- کلیدها را به صورت دوره‌ای جایگزین (Rotate) کنید

## استفاده از API

برای مشاهده مستندات مربوط به اندپوینت‌های موجود و نحوه احراز هویت، به [مرجع API](/docs/api-reference) مراجعه کنید.
