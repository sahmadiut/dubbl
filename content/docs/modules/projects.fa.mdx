## پروژه‌ها

پروژه‌ها به شما امکان می‌دهند زمان و بودجه کارهای مربوط به مشتری را پیگیری کنید.

### فیلدهای پروژه

| فیلد | توضیحات |
|---|---|
| نام (Name) | نام پروژه |
| مشتری (Client) | مخاطب مرتبط |
| وضعیت (Status) | فعال (Active)، تکمیل‌شده (Completed)، بایگانی‌شده (Archived) |
| بودجه (Budget) | کل بودجه به سنت (cents) |
| نرخ ساعتی (Hourly Rate) | نرخ پیش‌فرض برای ورودی‌های زمان |
| تاریخ شروع / پایان (Start / End Date) | جدول زمانی پروژه |

## ورودی‌های زمان

از طریق صفحه جزئیات پروژه، زمان صرف‌شده برای پروژه‌ها را ثبت کنید.

هر ورودی زمان شامل موارد زیر است:
- **تاریخ (Date)** — زمانی که کار انجام شده است
- **توضیحات (Description)** — آنچه روی آن کار شده است
- **مدت زمان (Duration)** — ساعت و دقیقه
- **قابل‌صورت‌حساب (Billable)** — اینکه آیا این زمان قابل‌صورت‌حساب است یا خیر

## صدور فاکتورها

از صفحه جزئیات پروژه، روی **Generate Invoice** (صدور فاکتور) کلیک کنید تا:

۱. تمام ورودی‌های زمانیِ قابل‌صورت‌حساب و فاکتورنشده جمع‌آوری شوند
۲. فاکتوری با اقلام ردیفی مجزا برای هر ورودی ایجاد شود
۳. ورودی‌های زمانی به عنوان فاکتورشده علامت‌گذاری شوند
۴. مبلغ کل فاکتورشده پروژه به‌روزرسانی شود

برای صدور فاکتور، پروژه باید دارای یک مخاطب مرتبط باشد.

## پیگیری بودجه

صفحه پروژه موارد زیر را نمایش می‌دهد:
- **مجموع ساعات (Total Hours)** — مجموع کل زمان‌های ثبت‌شده
- **مجموع صورت‌حساب‌شده (Total Billed)** — مجموع تمام مبالغ فاکتورشده
- **بودجه مصرف‌شده (Budget Used)** — درصد بودجه مصرف‌شده
