## دارایی‌های ثابت

تجهیزات، ماشین‌آلات، وسایل نقلیه، مبلمان اداری و سایر دارایی‌های سرمایه‌ای را در طول عمر مفید آن‌ها رهگیری کنید.

### فیلدهای دارایی

| فیلد | توضیحات |
|---|---|
| نام | شرح یا عنوان دارایی |
| شماره دارایی | شناسه یکتای دارایی (مثلاً FA-001) |
| تاریخ خرید | زمان تحصیل یا خرید دارایی |
| بهای تمام‌شده خرید | بهای اولیه به واحد فرعی (سنت/ریال) |
| ارزش اسقاط | ارزش تخمینی در پایان عمر مفید (واحد فرعی) |
| عمر مفید | عمر مفید تخمینی به ماه |
| روش استهلاک | خط مستقیم (Straight Line) یا نزولی (Declining Balance) |

## روش‌های استهلاک

### روش خط مستقیم (Straight Line)

مبلغ استهلاک ماهانه مساوی و ثابت:

```
استهلاک ماهانه = (بهای خرید - ارزش اسقاط) / تعداد ماه‌های عمر مفید
```

### روش نزولی مضاعف (Declining Balance)

نرخ نزولی مضاعف اعمال‌شده بر ارزش دفتری خالص دارایی:

```
نرخ ماهانه = (۲ / تعداد ماه‌های عمر مفید)
استهلاک ماهانه = ارزش دفتری خالص × نرخ ماهانه
```

## ثبت استهلاک

روی دکمه **ثبت استهلاک** (Record Depreciation) در صفحه یک دارایی کلیک کنید تا:

1. مبلغ استهلاک ماهانه محاسبه شود
2. یک سند دفتر روزنامه ثبت گردد (بدهکار: هزینه استهلاک، بستانکار: استهلاک انباشته)
3. استهلاک انباشته و ارزش دفتری خالص دارایی به‌روزرسانی شوند

از گزینه **محاسبه و ثبت استهلاک دوره‌ای** (Run Depreciation) در صفحه لیست دارایی‌ها برای پردازش همزمان تمام دارایی‌های فعال استفاده کنید.

## اسقاط یا واگذاری دارایی (Disposal)

هنگام واگذاری، فروش یا اسقاط یک دارایی:

1. تاریخ واگذاری و مبلغ فروش را وارد کنید
2. یک سند روزنامه ثبت می‌کند:
   - **بدهکار:** استهلاک انباشته (جهت بستن حساب)
   - **بستانکار:** حساب دارایی ثابت (جهت خروج دارایی از دفاتر)
   - **بدهکار/بستانکار:** سود یا زیان ناشی از واگذاری دارایی

## وضعیت‌های دارایی

- **فعال (Active)** — در حال استفاده و مشمول استهلاک
- **مستهلک‌شده کامل (Fully Depreciated)** — ارزش دفتری خالص برابر با ارزش اسقاط است
- **واگذارشده / اسقاط‌شده (Disposed)** — دارایی به فروش رسیده یا اسقاط شده است
