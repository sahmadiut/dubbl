## پروژه‌ها

پروژه‌ها به شما امکان می‌دهند زمان و بودجه صرف‌شده برای کارهای مشتریان را رهگیری و مدیریت کنید.

### فیلدهای پروژه

| فیلد | توضیحات |
|---|---|
| نام | نام پروژه |
| مشتری | مخاطب یا مشتری مرتبط |
| وضعیت | فعال (Active)، تکمیل‌شده (Completed)، آرشیوشده (Archived) |
| بودجه | کل بودجه به واحد فرعی (سنت/ریال) |
| نرخ ساعتی | نرخ پیش‌فرض برای ثبت‌های زمانی |
| تاریخ شروع / پایان | جدول زمانی پروژه |

## ثبت کارکرد زمانی (Time Entries)

کارکرد زمانی پروژه‌ها را از صفحه جزئیات هر پروژه ثبت کنید.

هر ثبت زمان شامل موارد زیر است:
- **تاریخ** — زمانی که کار انجام شده است
- **شرح** — کاری که بر روی آن فعالیت شده است
- **مدت زمان** — ساعات و دقایق
- **قابل صورت‌حساب** — آیا این زمان به مشتری فاکتور می‌شود یا خیر

## صدور فاکتور

در صفحه جزئیات پروژه، روی **صدور فاکتور** (Generate Invoice) کلیک کنید تا:

1. تمام ثبت‌های زمانیِ فاکتورنشده و قابل صورت‌حساب گردآوری شوند
2. فاکتوری با اقلام مجزا برای هر ثبت کارکرد زمانی ایجاد شود
3. ثبت‌های زمانی به عنوان صورت‌حساب‌شده علامت‌گذاری شوند
4. مجموع مبلغ فاکتورشده پروژه به‌روزرسانی گردد

پروژه برای صدور فاکتور باید یک مخاطب مرتبط داشته باشد.

## ردیابی بودجه

صفحه پروژه موارد زیر را نمایش می‌دهد:
- **مجموع ساعات** — جمع کل زمان ثبت‌شده
- **مجموع فاکتورشده** — جمع کل مبالغ فاکتورشده
- **بودجه مصرف‌شده** — درصد بودجه مصرف‌شده نسبت به کل بودجه
