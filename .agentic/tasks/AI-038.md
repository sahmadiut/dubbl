# AI-038 - Integrate the durable provider and tool execution loop

## Objective and implementation scope

Required implementation child of AI-035. Consume AI-037 attempts and AI-032
operations in the actual dependent-turn executor. No polling process or activation.

## Inputs

[AI-035](AI-035.md), [AI-037](AI-037.md), [execution contract](../docs/AI_EXECUTION_CONTRACT.md), AI-029/030 progress/input services.

## Acceptance criteria

- [ ] Execute dependent provider/tool turns with stable persisted associations, current authorization and all cumulative ceilings. Never reconstruct execution authority from redacted history or replay uncertain writes; sensitive work requires the separate approval service and is denied until qualified.
- [ ] Integrate durable clarification/answer/resume without resetting limits, minimized permission-checked context, grounded safe final summaries and real record links. Treat every text source as untrusted and never collect private reasoning.
- [ ] Orchestrate only bounded transient provider/read retries with new charged attempt identities and no implicit switch. Verify real REST/MCP/database dependent execution, permission/cancellation changes, partial success and separate-process restart. Add the raw bounded transport integration, retaining disabled live calls and honest provider/hosting limitations; pass relevant drift/typecheck/lint checks.

## Handoff

Consume executeProviderAttempt from lib/ai/provider-attempts.ts and AI-032's
executeToolOperation using the fresh accepted call's stable operationKey and
original validated arguments. The primitive never reconstructs arguments from
storage; an orphaned accepted call must fail/reconcile rather than replay display
data. It discards model final text and does not complete a run. Build live
record-disclosure-safe history before each turn, integrate the bounded raw UTF-8
adapter with live qualification still disabled, and implement clarification,
bounded retries and grounded outcomes. See AI_PROVIDER_ATTEMPTS.md. AI-035
independently integrates all original criteria after AI-037/038. AI-036 retains
polling, heartbeat/shutdown and provisional observation acceptance.
