# MON-041 - Adopt exact quote contracts

## Objective and implementation scope

Quotes REST/MCP CRUD, send/accept/decline and invoice conversion/progress billing, preserving decimal-major prices, stored units, discounts, tax, references and transaction semantics. Public/PDF boundaries remain MON-016.

## Inputs

Parent [MON-019](MON-019.md), MON-011 evidence, ADR-006, MONEY_MANIFEST and actual source. Requirements: [migration](../sources/SOURCE.md#database-and-currency-migration) and [API compatibility](../sources/SOURCE.md#api-backward-compatibility).

## Acceptance criteria

- [x] Every boundary in this slice has documented inputs, outputs, units, exact aliases and supported ranges.
- [x] Actual REST/MCP fixtures cover legacy and exact clients, authorization and organization isolation.
- [x] Invalid or unsupported values fail before mutation; responses preserve numeric compatibility without bigint crashes or silent precision/unit loss.

## Verification

Run meaningful operation fixtures, typecheck and lint. No builds or unrequested dev server.

## Handoff

Implemented exact quote contracts across nine REST and nine registered MCP
operations. Shared direct-DB services preserve REST-major/MCP-minor prices with
exact aliases, scoped atomic CRUD/status/conversion, price lookup and supported
references. Draft updates whitelist fields; billing uses integer ratios/sums,
precise remaining allocation and serialized conversion/numbering. Invalid/unsafe
or foreign input/history rejects before mutation. Invoice helpers are exported
without behavior changes. Contract registry, API/money docs, source inventory,
unit/actual operation fixtures and honest self-review accompany this slice.

120 unit tests and three migrated PostgreSQL quote/invoice workers passed;
typecheck and lint passed (159 preexisting warnings, zero errors). Temporary
synthetic PostgreSQL cluster stopped, zero fixture databases remaining. Full
controller suite passed (31 passed, one Windows symlink privilege skip). Full
int64/domain, provider/email/PDF/UI/session/OAuth, external-writer/config races
and financial/release qualifications retain their assigned gates; IRR unchanged.
MON-019 retains combined acceptance. No slice blocker; next task MON-042.
