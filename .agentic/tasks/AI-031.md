# AI-031 - Execute and recover the metered bounded provider worker

## Objective and implementation scope

Child of AI-023. Implement its actual provider/tool executor using lifecycle leases, safe observation and durable clarification. This child does not accept AI-023 or AI-007, enable rollout or qualify a live provider.

## Inputs

[AI-023](AI-023.md), AI-002..006 source/evidence, [execution contract](../docs/AI_EXECUTION_CONTRACT.md), [product experience](../docs/AI_PRODUCT_EXPERIENCE.md).

## Acceptance criteria

- [ ] Implement explicit polling worker entrypoint, graceful shutdown and fenced lifecycle ownership; deterministic provider scenarios exercise dependent tools, grounded final links, clarification/resume and truthful queue/unavailable conditions.
- [ ] Recheck current identity, configuration snapshots, policy and kill switch immediately before every provider/tool action; enforce step/request/token/output/time/cost limits with usage reservations and trusted callbacks, including retries and unknown usage.
- [ ] Persist ordered idempotent operations/events; retry only bounded transient reads/provider attempts and reconcile uncertain writes without duplicate effects. Cancellation/restart preserve partial effects and do not reset execution budgets.
- [ ] Treat prompts/documents/tools as untrusted data and publish safe summaries only. Verify provisional streaming versus confirmed persisted results, live permission checks, cursor loss/reconnect, delayed responses, cancellation during effects and bounded histories through real REST/MCP/database and deterministic provider fault/race tests.
- [ ] Pass typecheck/lint, disposable database integrations, capability/coverage/schema drift and controller/diff checks; document explicit worker startup and unqualified provider/hosting limitations.

## Verification

Deterministic fake provider and real registered tools/routes/database; separate process restart and concurrency tests. No live provider, build or dev server.

## Handoff

Not started. AI-023 independently integrates all children against its unchanged acceptance criteria.
