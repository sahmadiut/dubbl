## Acceptance criteria

- [x] Supply an explicit polling entrypoint, maintenance/claim/heartbeat/recovery and graceful shutdown; verify competing workers and separate-process restart with deterministic providers, dependent tools, grounded final links and durable clarification/resume.
- [x] Recheck live identity, policy/configuration snapshots, kill switch and cancellation before every provider/tool action; enforce step/request/token/output/time/cost ceilings using usage reservations and trusted callbacks. Retry only bounded transient reads/provider attempts; unknown usage remains charged/reserved and restart never resets budgets.
- [x] Treat all model/user/document/tool text as untrusted; validate complete unique calls before dispatch, reject malformed/oversized output and unknown finish reasons, and publish safe summaries with no private reasoning. Sensitive operations require the separate approval boundary and uncertain writes cannot replay.
- [x] Exercise provisional streaming versus persisted confirmed results, live disclosure permissions, cursor loss/reconnect, delayed responses, cancellation during effects, rate/quota/unavailable queue conditions and bounded histories through real REST/MCP/database and deterministic fault/race tests.
- [x] Pass typecheck/lint, disposable integrations, capability/coverage/schema drift and controller/diff checks; document startup and unqualified provider/hosting limitations. No live calls, build, dev server or rollout activation.
