ماژول صدور فاکتور، جریان کاری حساب‌های دریافتنی شما را مدیریت می‌کند.

## چرخه حیات فاکتور

```
Draft → Sent → Partial/Paid
              → Overdue
              → Void
```

۱. **پیش‌نویس (Draft)** - ایجاد و ویرایش بدون محدودیت
۲. **ارسال‌شده (Sent)** - نهایی‌سازی فاکتور و ایجاد سند حسابداری (بدهکار: حساب‌های دریافتنی، بستانکار: درآمد)
۳. **پرداخت جزئی (Partial)** - دریافت بخشی از مبلغ فاکتور
۴. **پرداخت‌شده (Paid)** - تسویه کامل
۵. **سررسیدگذشته (Overdue)** - سپری شدن تاریخ سررسید و عدم پرداخت
۶. **باطل‌شده (Void)** - لغوشده

## ایجاد یک فاکتور

۱. به مسیر **فروش > فاکتورها > فاکتور جدید (Sales > Invoices > New Invoice)** بروید
۲. یک **مخاطب** (مشتری) را انتخاب کنید
۳. **تاریخ صدور** و **تاریخ سررسید** را تعیین کنید
۴. **اقلام فاکتور** را همراه با شرح، تعداد، قیمت واحد و حساب مربوطه اضافه کنید
۵. در صورت تمایل، یک **شماره عطف / مرجع** (مانند شماره سفارش خرید یا PO) و **یادداشت‌ها** را درج کنید
۶. فاکتور را به‌صورت پیش‌نویس ذخیره کرده یا بلافاصله ارسال کنید

## اقلام فاکتور

هر قلم فاکتور شامل موارد زیر است:

| فیلد | شرح |
|-------|-------------|
| Description | موردی که بابت آن صورتحساب صادر می‌کنید |
| Quantity | تعداد واحدها (ذخیره‌شده به‌صورت تعداد × ۱۰۰) |
| Unit Price | قیمت هر واحد به سنت |
| Account | حساب درآمدی که بستانکار می‌شود |
| Tax Rate | نرخ مالیات اختیاری |
| Amount | محاسبه خودکار: تعداد × قیمت |

## ارسال فاکتورها

هنگامی که روی گزینه **ارسال (Send)** در یک فاکتور پیش‌نویس کلیک می‌کنید، کادری شامل موارد زیر نمایش داده می‌شود:

- **گیرنده (To)** - به‌صورت پیش‌فرض با نشانی ایمیل مخاطب پر شده و قابل ویرایش است
- **موضوع (Subject)** - به‌صورت پیش‌فرض با شماره فاکتور و نام سازمان شما پر شده است
- **پیام (Message)** - قالب پیش‌فرضی که شامل نام مخاطب، مبلغ قابل‌پرداخت و تاریخ سررسید است
- **پیوست PDF (Attach PDF)** - چک‌باکسی برای ضمیمه کردن فایل PDF فاکتور (به‌صورت پیش‌فرض فعال است)

شما دو گزینه در اختیار دارید:

- **ارسال ایمیل (Send Email)** - ایمیل را برای گیرنده ارسال کرده و وضعیت فاکتور را به «ارسال‌شده» تغییر می‌دهد
- **علامت‌گذاری به‌عنوان ارسال‌شده (Mark as Sent)** - وضعیت فاکتور را بدون ارسال ایمیل تغییر می‌دهد

### تاریخچه ایمیل

پس از ارسال، بخش **تاریخچه ایمیل (Email History)** در صفحه جزئیات فاکتور ظاهر می‌شود و تمام ایمیل‌های ارسال‌شده برای آن فاکتور را نشان می‌دهد. هر ردیف شامل گیرنده، موضوع، وضعیت (ارسال‌شده/ناموفق) و برچسب زمانی است. شما می‌توانید هر یک از ایمیل‌های قبلی را مجدداً ارسال کنید (**Resend**).

### محدودیت‌های ارسال ایمیل

ارسال ایمیل مشمول محدودیت‌های ماهانه بر اساس پلن اشتراک شما است:

| پلن | ایمیل/ماه |
|------|-------------|
| رایگان (Free) | ۲۵ |
| حرفه‌ای (Pro) | ۱۰۰ |
| افزونه فضای ذخیره‌سازی (Storage add-on) | تا ۱۰,۰۰۰ |

## ثبت پرداخت‌ها

از صفحه جزئیات فاکتور، روی **ثبت پرداخت (Record Payment)** کلیک کرده و مقادیر زیر را وارد کنید:

- **مبلغ (Amount)** - مبلغ پرداختی به سنت
- **تاریخ (Date)** - تاریخ پرداخت

این کار یک سند حسابداری پرداخت ایجاد می‌کند (بدهکار: بانک، بستانکار: حساب‌های دریافتنی) و مانده فاکتور را به‌روزرسانی می‌کند.

## دانلود فایل‌های PDF

فاکتورها را می‌توان به‌صورت فایل‌های PDF از چندین بخش دانلود کرد:

- از صفحه جزئیات فاکتور، با کلیک روی **دانلود PDF (Download PDF)**
- از صفحه پرداخت مشتری، با کلیک روی **دانلود فاکتور (Download Invoice)**
- از طریق رابط برنامه‌نویسی: `GET /api/v1/invoices/{id}/pdf?format=pdf`
- از طریق MCP: با استفاده از ابزار `get_invoice_pdf`

برای سفارشی‌سازی نحوه نمایش فایل‌های PDF، به بخش [قالب‌ها](/docs/settings/document-templates) مراجعه کنید.

## شماره‌گذاری فاکتورها

فاکتورها به‌صورت خودکار و متوالی شماره‌گذاری می‌شوند: `INV-00001`، `INV-00002` و غیره. پیشوند فاکتورها قابل تنظیم و پیکربندی است.

## تبدیل پیش‌فاکتور به فاکتور

پیش‌فاکتورهای تایید و پذیرفته‌شده می‌توانند مستقیماً به فاکتور تبدیل شوند و کلیه اقلام فاکتور کپی خواهند شد.

## پورتال مشتریان

مشتریان می‌توانند از طریق یک لینک پورتال، فاکتورها را مشاهده و پرداخت کنند. این پورتال جزئیات فاکتور، وضعیت پرداخت و دکمه دانلود PDF را ارائه می‌دهد. پیوندهای پورتال با توکن‌های امنیتی محافظت می‌شوند و می‌توان برای آن‌ها تاریخ انقضا تعیین کرد.

## مرجع API

| نقطه پایانی (Endpoint) | متد | شرح |
|----------|--------|-------------|
| `/api/v1/invoices` | GET | فهرست فاکتورها |
| `/api/v1/invoices` | POST | ایجاد فاکتور |
| `/api/v1/invoices/{id}` | GET | دریافت جزئیات فاکتور |
| `/api/v1/invoices/{id}` | PATCH | به‌روزرسانی فاکتور |
| `/api/v1/invoices/{id}/pdf` | GET | دریافت HTML فاکتور |
| `/api/v1/invoices/{id}/pdf?format=pdf` | GET | دانلود PDF فاکتور |
| `/api/v1/invoices/{id}/compliance` | GET | بررسی هشدارهای انطباق |
