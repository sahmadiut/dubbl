## نمای کلی

دابل (Dubbl) برای صورت‌حساب اشتراک‌ها از Stripe استفاده می‌کند. برای هر سازمان دو نوع اشتراک مستقل وجود دارد:

- **طرح صندلی (کاربر)** - پرو (۱۲ دلار/صندلی/ماه یا ۱۰ دلار/صندلی/ماه در پرداخت سالانه) برای دسترسی تیمی، گزارش‌ها، API و پشتیبانی از چند ارز
- **افزونه فضای ذخیره‌سازی** - سطوح Starter، Growth یا Scale برای فضای ذخیره‌سازی فایل و محدودیت‌های ارسال ایمیل

هر دو اشتراک به‌صورت مجزا در Stripe مدیریت می‌شوند و امکان ارتقا یا تنزل مستقل آن‌ها وجود دارد.

## راه‌اندازی Stripe

<Steps>
  <Step>
    ### ایجاد حساب کاربری Stripe

    در [stripe.com](https://stripe.com) ثبت‌نام کرده و فرایند راه‌اندازی اولیه (Onboarding) را تکمیل کنید. برای آزمایش، از حالت آزمایشی (Test mode) استرایپ استفاده نمایید.
  </Step>
  <Step>
    ### ایجاد محصولات و قیمت‌ها

    در پیشخوان Stripe، محصولات زیر را با قیمت‌های دوره‌ای ایجاد کنید:

    **طرح‌های صندلی:**
    | محصول | قیمت (ماهانه) | قیمت (سالانه) |
    |---------|----------------|----------------|
    | Pro | ۱۲ دلار/صندلی/ماه | ۱۲۰ دلار/صندلی/سال (معادل ۱۰ دلار/ماه) |

    **افزونه‌های فضای ذخیره‌سازی:**
    | محصول | قیمت (ماهانه) | قیمت (سالانه) |
    |---------|----------------|----------------|
    | Starter (۲۵ گیگابایت) | ۱۵ دلار/ماه | ۱۵۶ دلار/سال (معادل ۱۳ دلار/ماه) |
    | Growth (۷۵ گیگابایت) | ۴۵ دلار/ماه | ۴۵۶ دلار/سال (معادل ۳۸ دلار/ماه) |
    | Scale (۳۰۰ گیگابایت) | ۱۲۰ دلار/ماه | ۱,۲۰۰ دلار/سال (معادل ۱۰۰ دلار/ماه) |
  </Step>
  <Step>
    ### پیکربندی متغیرهای محیطی

    شناسه هر قیمت (price ID) را از پیشخوان Stripe کپی کرده و به فایل `.env.local` خود اضافه کنید:

    ```bash
    # کلیدهای API استرایپ
    STRIPE_SECRET_KEY="sk_test_..."
    STRIPE_WEBHOOK_SECRET="whsec_..."

    # شناسه‌های قیمت طرح صندلی
    STRIPE_PRO_PRICE_ID="price_..."
    STRIPE_PRO_ANNUAL_PRICE_ID="price_..."

    # شناسه‌های قیمت افزونه ذخیره‌سازی (ماهانه)
    STRIPE_STORAGE_STARTER_PRICE_ID="price_..."
    STRIPE_STORAGE_GROWTH_PRICE_ID="price_..."
    STRIPE_STORAGE_SCALE_PRICE_ID="price_..."

    # شناسه‌های قیمت افزونه ذخیره‌سازی (سالانه)
    STRIPE_STORAGE_STARTER_ANNUAL_PRICE_ID="price_..."
    STRIPE_STORAGE_GROWTH_ANNUAL_PRICE_ID="price_..."
    STRIPE_STORAGE_SCALE_ANNUAL_PRICE_ID="price_..."
    ```
  </Step>
  <Step>
    ### راه‌اندازی وب‌هوک

    یک نقطه پایانی وب‌هوک (webhook endpoint) در Stripe ایجاد کنید که به آدرس زیر اشاره داشته باشد:

    ```
    https://your-domain.com/api/stripe/webhook
    ```

    در رویدادهای زیر مشترک شوید:
    - `checkout.session.completed`
    - `customer.subscription.updated`
    - `customer.subscription.deleted`

    کلید مخفی امضای وب‌هوک (signing secret) را در `STRIPE_WEBHOOK_SECRET` کپی کنید.
  </Step>
</Steps>

## نحوه عملکرد ارتقای طرح

هنگامی که کاربری طرح خود را ارتقا می‌دهد یا تغییر می‌دهد:

۱. اگر کاربر از قبل اشتراک فعالی داشته باشد، دابل تابع `stripe.subscriptions.update()` را با شناسه قیمت جدید فراخوانی می‌کند
۲. استرایپ هزینه را به‌صورت خودکار بر اساس مدت‌زمان باقی‌مانده از دوره صورت‌حساب تسهیم به‌نسبت (Prorate) می‌کند
۳. پایگاه داده محلی بلافاصله به‌روزرسانی می‌شود
۴. هیچ اشتراک تکراری ایجاد نمی‌شود

برای اشتراک‌های جدید، یک نشست Stripe Checkout ایجاد شده و کاربر برای تکمیل پرداخت هدایت می‌شود.

## آزمایش با Stripe CLI

برای توسعه محلی، از Stripe CLI جهت فوروارد رویدادهای وب‌هوک (webhook) استفاده کنید:

```bash
# نصب Stripe CLI
brew install stripe/stripe-cli/stripe

# ورود به حساب Stripe
stripe login

# هدایت رویدادها به سرور محلی شما
stripe listen --forward-to localhost:3000/api/stripe/webhook
```

این CLI یک کلید امضای وب‌هوک (signing secret) نمایش می‌دهد که با `whsec_` شروع می‌شود. از این مقدار به‌عنوان `STRIPE_WEBHOOK_SECRET` برای تست‌های محلی استفاده کنید.

### شماره کارت‌های آزمایشی

| شماره کارت | نتیجه |
|-------------|--------|
| `4242 4242 4242 4242` | پرداخت موفق |
| `4000 0000 0000 3220` | نیاز به احراز هویت 3D Secure |
| `4000 0000 0000 9995` | تراکنش ناموفق (موجودی ناکافی) |

از هر تاریخ انقضایی در آینده و هر کد CVC ۳ رقمی می‌توانید استفاده کنید.

## پورتال مشتریان (Customer Portal)

کاربران می‌توانند صورت‌حساب خود را (به‌روزرسانی روش پرداخت، لغو اشتراک، مشاهده صورت‌حساب‌ها) از طریق Stripe Customer Portal مدیریت کنند. برای فعال‌سازی آن:

1. به مسیر Stripe Dashboard > Settings > Customer Portal بروید
2. قابلیت‌های مورد نظر خود را فعال کنید (سوابق فاکتورها، لغو اشتراک و غیره)
3. دسترسی به این پورتال از طریق دکمه‌ی «Manage Billing» در مسیر Settings > Billing امکان‌پذیر است

## میزبانی شخصی بدون Stripe

بخش صورت‌حساب و پلن‌ها اختیاری است. بدون پیکربندی Stripe، همه سازمان‌ها به‌صورت پیش‌فرض در پلن رایگان قرار می‌گیرند. مدیران سایت می‌توانند محدودیت‌های پلن را برای هر سازمان به‌صورت دستی از پنل مدیریت در مسیر `/admin/organizations` تغییر دهند.

<Callout type="info">
  نمونه‌های خودمیزبان (Self-hosted) می‌توانند بدون نیاز به Stripe، محدودیت‌های سفارشی برای پلن‌ها تعریف کنند (مانند تعداد نامحدود اعضا، فضای ذخیره‌سازی و غیره).
</Callout>
