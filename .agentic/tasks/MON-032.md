## Objective and implementation scope

lib/api/backup-snapshot.ts, backup storage/maintenance, REST backup upload/download/create/restore and MCP backups. Version snapshots deliberately, validate exact/legacy money and organization/reference ownership before destructive restore, preserve immutable old files and prove failed restoration leaves existing data intact.
