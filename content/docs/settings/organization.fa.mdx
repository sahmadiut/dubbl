## تنظیمات عمومی

برای پیکربندی سازمان خود به بخش **تنظیمات** (Settings) بروید.

### مشخصات سازمان

| فیلد | توضیحات |
|---|---|
| نام | نام نمایشی سازمان شما |
| کشور | کشور اصلی محل فعالیت |
| ارز پایه | ارز پیش‌فرض برای گزارش‌ها |
| شروع سال مالی | نخستین ماه از سال مالی شما |
| شناسه مالیاتی | شماره شناسه مالیاتی کسب‌وکار شما |

## تنظیمات API و MCP

پاسخ‌های مربوط به سازمان شامل رشته‌های عددی صحیح دقیق `mileageRateMinor` و `billApprovalThresholdMinor` در کنار فیلدهای عددی موجود خود هستند. مقادیر ذخیره‌شده `null` همچنان `null` باقی می‌مانند. مبالغ، واحدهای فرعی ارز خود (مانند سنت برای دلار آمریکا) را حفظ می‌کنند؛ درصدها نیز به‌صورت نقاط پایه عددی باقی می‌مانند.

برای به‌روزرسانی تنظیمات ارائه‌شده از `PATCH /api/v1/organization` یا ابزار MCP به نام `update_organization` استفاده کنید. فیلدهای ذکرنشده بدون تغییر باقی می‌مانند؛ مقدار `null` متن اختیاری را پاک می‌کند. این مورد شامل شناسه طرف مشارکت (participant identifier) و طرح (scheme) سامانه PEPPOL از صفحه تنظیمات نیز می‌شود. فیلدهای ناشناخته رد می‌شوند. تغییر ارز عملیاتی مستلزم دسترسی `manage:billing` است و در صورت وجود فعالیت در دفتر روزنامه رد خواهد شد. انتخاب ریال ایران (IRR) تا زمان احراز صلاحیت مالی غیرفعال باقی می‌ماند.

برای تنظیمات مسافت‌پیمایی (mileage) از `GET` یا `PUT /api/v1/organization/mileage-rate`، یا ابزارهای MCP به نام `get_organization_mileage_rate` و `update_organization_mileage_rate` استفاده کنید. عملیات نوشتن نیازمند مجوز `manage:tax-config` است. مقدار `mileageRate` (یک عدد صحیح) یا `mileageRateMinor` (یک رشته دقیق)، یا مقادیر منطبق برای هر دو را ارائه دهید. نرخ‌ها بر حسب **واحدهای فرعی ارز به ازای هر مایل** هستند: برای USD مقدار `67` به معنی ۰.۶۷ دلار به ازای هر مایل است. بازه پشتیبانی‌شده بین ۰ تا ۹۰۰۷۱۹۹۲۵۴۷۴۰۹۹۱ است؛ مقادیر هرگز مقیاس‌بندی مجدد نمی‌شوند. یک مقدار ذخیره‌شده `null`، مقدار پیش‌فرض جایگزین موجود در اندپوینت مسافت‌پیمایی یعنی `67` را حفظ می‌کند.

## صورت‌حساب

برای مدیریت اشتراک خود، مشاهده فاکتورها و به‌روزرسانی روش‌های پرداخت، به مسیر **تنظیمات > صورت‌حساب** (Settings > Billing) بروید.

## اعضای تیم

برای مدیریت افرادی که به سازمان شما دسترسی دارند، به مسیر **تنظیمات > اعضا** (Settings > Members) بروید.

### دعوت از اعضا

۱. روی **Invite Member** (دعوت از عضو) کلیک کنید
۲. آدرس ایمیل را وارد کنید
۳. یک نقش را انتخاب کنید
۴. کاربر دعوت‌شده ایمیلی برای پیوستن دریافت می‌کند

### نقش‌ها

| نقش | مجوزها |
|---|---|
| مالک (Owner) | دسترسی کامل، امکان حذف سازمان |
| مدیر (Admin) | دسترسی کامل به‌جز حذف سازمان |
| عضو (Member) | دسترسی استاندارد به تمام ماژول‌ها |
| مشاهده‌کننده (Viewer) | دسترسی صرفاً خواندنی |

## مشاوران

برای دعوت از مشاوران خارجی (حسابداران، دفترداران) با دسترسی کنترل‌شده به دفاتر مالی خود، به مسیر **تنظیمات > مشاوران** (Settings > Advisors) بروید.
