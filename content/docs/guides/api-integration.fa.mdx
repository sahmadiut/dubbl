## ایجاد کلید API

۱. به **تنظیمات ← کلیدهای API** بروید
۲. روی **ایجاد کلید API** کلیک کنید
۳. کلید را کپی کنید — این کلید دیگر نمایش داده نخواهد شد

## ارسال درخواست‌ها

کلید API و شناسه سازمان (Organization ID) را در هر درخواست قرار دهید:

```bash
curl -X GET \
  -H "Authorization: Bearer your-api-key-here" \
  -H "x-organization-id: your-org-id" \
  https://your-instance.com/api/v1/contacts
```

## نمونه: ایجاد یک فاکتور

```bash
curl -X POST \
  -H "Authorization: Bearer your-api-key" \
  -H "x-organization-id: your-org-id" \
  -H "Content-Type: application/json" \
  -d '{
    "contactId": "contact-id",
    "issueDate": "2026-03-01",
    "dueDate": "2026-03-31",
    "lines": [
      {
        "description": "Web Development",
        "quantity": 100,
        "unitPrice": 15000,
        "accountId": "revenue-account-id"
      }
    ]
  }' \
  https://your-instance.com/api/v1/invoices
```

## نمونه: فهرست‌بندی مخاطبان همراه با فیلتر

```bash
# جستجوی مشتریان
curl -H "Authorization: Bearer your-api-key" \
  -H "x-organization-id: your-org-id" \
  "https://your-instance.com/api/v1/contacts?type=customer&search=acme&page=1&limit=20"
```

## صفحه‌بندی

اندپوینت‌های فهرست از صفحه‌بندی پشتیبانی می‌کنند:

| پارامتر | پیش‌فرض | توضیحات |
|---|---|---|
| `page` | 1 | شماره صفحه |
| `limit` | 20 | تعداد اقلام در هر صفحه (حداکثر ۱۰۰) |

پاسخ دریافتی شامل فراداده‌های صفحه‌بندی است:

```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 45,
    "totalPages": 3
  }
}
```

## مدیریت خطاها

خطاهای API کدهای وضعیت HTTP متناسب را برمی‌گردانند:

| کد | توضیحات |
|---|---|
| 400 | خطای اعتبارسنجی (فیلد `error` را بررسی کنید) |
| 401 | احراز هویت انجام نشده یا نامعتبر است |
| 403 | دسترسی ناکافی است |
| 404 | منبع یافت نشد |
| 500 | خطای داخلی سرور |

## مجوزها

سطح دسترسی کلید API از نقش کاربری که آن را ایجاد کرده است به ارث می‌رسد. مجوزهای در دسترس:

- `manage:contacts` — عملیات CRUD مخاطبان
- `manage:invoices` — عملیات CRUD فاکتورها
- `approve:invoices` — ارسال/باطل کردن فاکتورها
- `manage:bills` — عملیات CRUD صورت‌حساب‌های خرید
- `manage:banking` — عملیات حساب‌های بانکی
- `manage:expenses` — مطالبات هزینه
- `approve:expenses` — تأیید/رد هزینه‌ها
- `manage:inventory` — عملیات موجودی کالا
- `manage:projects` — مدیریت پروژه‌ها
- `manage:assets` — عملیات دارایی‌های ثابت
- `manage:payroll` — مدیریت حقوق و دستمزد
- `manage:budgets` — عملیات بودجه‌بندی
- `view:audit-log` — مشاهده رد پای حسابرسی (Audit Trail)
