# MON-039 - Adopt exact invoice CRUD write contracts

## Objective and implementation scope

REST invoice create/patch/delete and MCP create/update/delete parity. Decimal-major prices differ from stored minor units. Preserve verified rounding/default/price-list/credit-limit/approval behavior, add exact aliases and validate all references, sums, products and old/new locks before atomic writes.

## Inputs

Parent [MON-019](MON-019.md), MON-011 evidence, ADR-006, MONEY_MANIFEST and actual source. Requirements: [migration](../sources/SOURCE.md#database-and-currency-migration) and [API compatibility](../sources/SOURCE.md#api-backward-compatibility).

## Acceptance criteria

- [ ] Every boundary in this slice has documented inputs, outputs, units, exact aliases and supported ranges.
- [ ] Actual REST/MCP fixtures cover legacy and exact clients, authorization and organization isolation.
- [ ] Invalid or unsupported values fail before mutation; responses preserve numeric compatibility without bigint crashes or silent precision/unit loss.

## Verification

Run meaningful operation fixtures, typecheck and lint. No builds or unrequested dev server.
