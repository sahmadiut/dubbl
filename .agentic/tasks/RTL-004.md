# RTL-004 - Convert shared primitive layout and directional behavior

## Objective and implementation scope

Audit and convert flow-dependent physical layout in components/ui primitives to logical properties, including menus/select indicators, dialog/sheet close controls and headings, tabs, search/command, date/calendar navigation and directional chevrons. Preserve intentional physical geometry (centering, actual popover sides/animations), semantic DOM order, focus styling, explicit LTR fields and universal icons. Make shared drawer defaults open from the logical end while preserving documented physical side overrides. Inventory actual callers and explicit exceptions; do not touch dedicated Stripe/provider files.

## Inputs

- [RTL-001](RTL-001.md), [RTL-003](RTL-003.md), actual shared components and installed primitive contracts.
- [RTL strategy](../sources/SOURCE.md#rtl-uiux-strategy), DEC-005 and DEC-008.

## Acceptance criteria

- [x] Shared directional layout and drawer/menu/tab/popover behavior work for both directions, with intentional physical-side contracts inventoried.
- [x] Meaningful real component behavior/render tests preserve DOM order, focus semantics, canonical values, explicit overrides and non-directional icons.
- [x] Relevant static/regression checks pass and independent RTL-001 review remains open; no mounted/native review is invented.

## Verification

Discover and run task-appropriate real component/behavior tests, typecheck, lint and controller checks. No build or dev server. Record actual checks and browser availability; screenshot absence alone is not a blocker under DEC-005.
