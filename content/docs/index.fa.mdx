## شروع سریع

<Steps>
  <Step>
    ### کلون کردن مخزن و نصب وابستگی‌ها

    ```bash
    git clone https://github.com/dubbl-org/dubbl.git
    cd dubbl && pnpm install
    ```
  </Step>
  <Step>
    ### پیکربندی متغیرهای محیطی

    ```bash
    cp .env.example .env
    # فایل .env را با آدرس پایگاه داده و کلید امنیتی احراز هویت خود ویرایش کنید
    ```
  </Step>
  <Step>
    ### راه‌اندازی پایگاه داده

    ```bash
    pnpm db:push
    pnpm db:seed  # داده‌های نمایشی اختیاری
    ```
  </Step>
  <Step>
    ### اجرای برنامه

    ```bash
    pnpm dev
    ```

    آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر خود باز کنید.
  </Step>
</Steps>
