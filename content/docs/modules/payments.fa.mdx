صفحه «پرداخت‌ها» نمایی یکپارچه از تمامی فعالیت‌های پرداختی را ارائه می‌دهد. برای مشاهده پرداخت‌های مشتریان، به مسیر **فروش > پرداخت‌ها** بروید.

## ثبت پرداخت‌ها

پرداخت‌ها را می‌توان به چندین روش ثبت کرد:

- **از طریق فاکتور** - علامت‌گذاری فاکتور به‌عنوان پرداخت‌شده، به‌صورت جزئی یا کامل
- **از طریق قبض** - ثبت پرداخت در ازای قبض تأمین‌کننده
- **پرداخت‌های دسته‌ای** - پردازش هم‌زمان چندین پرداخت

## فیلدهای پرداخت

| فیلد | توضیحات |
|---|---|
| تاریخ | تاریخ پرداخت |
| طرف حساب | مشتری یا تأمین‌کننده |
| مبلغ | مبلغ پرداخت |
| روش | انتقال بانکی، نقد، کارت و غیره |
| شناسه مرجع | شناسه مرجع پرداخت یا شماره چک |
| حساب | حساب بانکی مورداستفاده |

## پرداخت‌های جزئی

فاکتورها و قبض‌ها از پرداخت جزئی پشتیبانی می‌کنند. مانده قابل پرداخت به‌طور خودکار به‌روزرسانی شده و وضعیت سند به «پرداخت جزئی» تغییر می‌یابد.

## اضافه‌پرداخت‌ها

چنانچه مبلغ پرداخت بیشتر از مبلغ فاکتور باشد، مبلغ مازاد به‌عنوان بستانکاری ثبت می‌شود که می‌توان آن را برای فاکتورهای آتی اعمال کرد.

## سند روزنامه

هنگام ثبت پرداخت مشتری:

| حساب | بدهکار | بستانکار |
|---|---|---|
| حساب بانکی | مبلغ | |
| حساب‌های دریافتنی | | مبلغ |

برای پرداخت به تأمین‌کنندگان، این ثبت معکوس می‌شود (بدهکار: حساب‌های پرداختنی، بستانکار: حساب بانکی).
