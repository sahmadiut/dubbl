# AI-037 - Fence and meter durable provider attempts

## Objective and implementation scope

Required implementation child of AI-035. Supply the durable single-provider-turn
boundary consumed by the loop, with injected server-owned raw transport and no
live connection, tool dispatch, polling process or rollout activation.

## Inputs

[AI-035](AI-035.md), [execution contract](../docs/AI_EXECUTION_CONTRACT.md),
[protocol boundary](../docs/AI_PROVIDER_PROTOCOL.md), usage and fenced tool services.

## Acceptance criteria

- [x] Atomically persist lease-fenced provider-attempt identities, immutable config/policy and original price/budget snapshots with usage reservations before action. Enforce persistent request/token/output/cost/payload/deadline ceilings; repeated keys cannot dispatch twice and new attempts cannot reset budgets or switch provider/model/price.
- [x] Validate complete raw responses through AI-034 before exposing calls and persist stable provider-call/tool-operation-key bindings. Recheck live authority, cancellation, runtime/kill switch, configuration and budgets after lock waits; settle trusted usage through revocation/stale callbacks without restoring execution authority. Unknown usage remains reserved and no saved display payload authorizes replay.
- [x] Verify deterministic transport, competing/stale executors, lock waits, quota/rate/config failures, timeout/invalid output and separate-process crash/restart through disposable PostgreSQL with real REST/MCP observation. Supply migrations, schema drift/typecheck/lint and honest remaining loop/provider/hosting limitations.

## Handoff

Implemented lib/ai/provider-attempts.ts and provider-recovery.ts, atomic internal
usage composition, canonical call/operation binding and migration 0023. See
[attempt contract](../docs/AI_PROVIDER_ATTEMPTS.md) and evidence/AI-037-attempt-1.md.
Only a fresh winning accepted receipt carries complete calls; persisted metadata
never reconstructs executable arguments. Unknown usage stays charged, recovered
keys never replay, original budgets/price/output limits survive successor attempts,
and current restrictions still apply. Existing public usage/progress REST/MCP
surfaces are unchanged and exercised through actual registered handlers.
AI-038 must supply the actual dependent loop, record-level context disclosure,
bounded raw UTF-8 transport integration, clarification, retries, sensitive-operation
approval denial/integration and grounded summaries. AI-035/033/031/023/007 remain
independent parents; AI-036 owns process/observation. No live call or activation.
