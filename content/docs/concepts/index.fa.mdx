---
title: مفاهیم حسابداری
description: با اصول و مبانی حسابداری که دابل بر پایهٔ آن‌ها بنا شده است آشنا شوید.
---

import { Cards, Card } from "fumadocs-ui/components/card";
import { Callout } from "fumadocs-ui/components/callout";

درک چند مفهوم اصلی حسابداری به شما کمک می‌کند بیشترین بهره را از دابل ببرید. چه حسابداری باتجربه باشید و چه صاحب کسب‌وکاری که برای نخستین بار امور مالی خود را پیگیری می‌کند، این صفحه‌ها اصول پشت هر قابلیت را توضیح می‌دهند.

<Callout type="info">
  تازه با حسابداری آشنا شده‌اید؟ برای شروع، [حسابداری برای صاحبان کسب‌وکارهای تک‌نفره](/docs/concepts/for-solopreneurs) را بخوانید.
</Callout>
