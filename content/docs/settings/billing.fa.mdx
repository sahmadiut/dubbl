## نمای کلی

دابل برای مدیریت و تسویه اشتراک‌ها از Stripe استفاده می‌کند. دو نوع اشتراک مستقل برای هر سازمان قابل تعریف است:

- **پلن کاربری (Seat Plan)** - نسخه حرفه‌ای Pro (۱۲ دلار به ازای هر کاربر در ماه یا ۱۰ دلار به صورت سالانه) برای دسترسی تیم، گزارش‌های پیشرفته، API و قابلیت چندارزی
- **پلن افزایش فضای ذخیره‌سازی** - سطوح پایه‌ای Starter، رشد Growth، یا سازمانی Scale برای حجم ذخیره‌سازی فایل و سقف ارسال ایمیل

هر دو اشتراک به صورت مجزا در Stripe مدیریت می‌شوند و می‌توانند مستقلاً ارتقا یا تنزل یابند.

## مراحل راه‌اندازی Stripe

<Steps>
  <Step>
    ### ساخت حساب کاربری Stripe

    در سایت [stripe.com](https://stripe.com) ثبت نام کرده و مراحل اعتبارسنجی را طی کنید. برای آزمایش، از حالت Test Mode استفاده نمایید.
  </Step>
  <Step>
    ### تعریف محصولات و قیمت‌ها

    در پیشخوان Stripe، محصولات زیر را با قیمت‌های دوره‌ای تعریف کنید:

    **پلن‌های کاربری:**
    | محصول | قیمت (ماهانه) | قیمت (سالانه) |
    |---|---|---|
    | Pro | ۱۲ دلار/کاربر/ماه | ۱۲۰ دلار/کاربر/سال (معادل ۱۰ دلار در ماه) |

    **افزودنی‌های فضای ذخیره‌سازی:**
    | محصول | قیمت (ماهانه) | قیمت (سالانه) |
    |---|---|---|
    | Starter (۲۵ گیگابایت) | ۱۵ دلار/ماه | ۱۵۶ دلار/سال (معادل ۱۳ دلار در ماه) |
    | Growth (۷۵ گیگابایت) | ۴۵ دلار/ماه | ۴۵۶ دلار/سال (معادل ۳۸ دلار در ماه) |
    | Scale (۳۰۰ گیگابایت) | ۱۲۰ دلار/ماه | ۱,۲۰۰ دلار/سال (معادل ۱۰۰ دلار در ماه) |
  </Step>
  <Step>
    ### تنظیم متغیرهای محیطی

    شناسه‌های قیمت (Price IDs) را از Stripe کپی کرده و در فایل `.env.local` قرار دهید:

    ```bash
    # کلیدهای API استرایپ
    STRIPE_SECRET_KEY="sk_test_..."
    STRIPE_WEBHOOK_SECRET="whsec_..."

    # شناسه‌های قیمت پلن‌های کاربری
    STRIPE_PRO_PRICE_ID="price_..."
    STRIPE_PRO_ANNUAL_PRICE_ID="price_..."

    # شناسه‌های قیمت فضای ذخیره‌سازی (ماهانه)
    STRIPE_STORAGE_STARTER_PRICE_ID="price_..."
    STRIPE_STORAGE_GROWTH_PRICE_ID="price_..."
    STRIPE_STORAGE_SCALE_PRICE_ID="price_..."

    # شناسه‌های قیمت فضای ذخیره‌سازی (سالانه)
    STRIPE_STORAGE_STARTER_ANNUAL_PRICE_ID="price_..."
    STRIPE_STORAGE_GROWTH_ANNUAL_PRICE_ID="price_..."
    STRIPE_STORAGE_SCALE_ANNUAL_PRICE_ID="price_..."
    ```
  </Step>
  <Step>
    ### تنظیم وب‌هوک (Webhook)

    یک اندپوینت وب‌هوک در استرایپ به نشانی زیر ایجاد کنید:

    ```
    https://your-domain.com/api/stripe/webhook
    ```

    در این رویدادها عضو شوید:
    - `checkout.session.completed`
    - `customer.subscription.updated`
    - `customer.subscription.deleted`

    سپس کلید امضای وب‌هوک را در `STRIPE_WEBHOOK_SECRET` کپی نمایید.
  </Step>
</Steps>

## نحوه ارتقای پلن‌ها

هنگامی که کاربری پلن خود را تغییر می‌دهد:

۱. اگر اشتراک فعالی داشته باشد، دابل متد `stripe.subscriptions.update()` را با شناسه قیمت جدید فراخوانی می‌کند
۲. استرایپ هزینه مانده دوره جاری را به طور دقیق و خودکار تعدیل و محاسبه می‌کند (Proration)
۳. پایگاه داده برنامه بلافاصله به‌روزرسانی می‌شود
۴. هیچ اشتراک تکراری یا موازی ایجاد نخواهد شد

## آزمایش با Stripe CLI

برای توسعه محلی، از ابزار Stripe CLI جهت هدایت رویدادها استفاده کنید:

```bash
# نصب خط فرمان استرایپ
brew install stripe/stripe-cli/stripe

# ورود به حساب
stripe login

# فوروارد رویدادها به سرور محلی
stripe listen --forward-to localhost:3000/api/stripe/webhook
```

## پرتال مشتریان (Customer Portal)

کاربران می‌توانند جزئیات اشتراک خود را از طریق پرتال مشتریان استرایپ مدیریت کنند. این صفحه از بخش تنظیمات > صورت‌حساب > کلید «مدیریت صورت‌حساب» در دسترس است.

## میزبانی اختصاصی (Self-Hosting) بدون نیاز به Stripe

استفاده از سیستم صورت‌حساب کاملاً اختیاری است. بدون پیکربندی Stripe، سازمان‌ها روی پلن رایگان قرار می‌گیرند و مدیران سامانه می‌توانند در پنل مدیریت `/admin/organizations` سقف منابع را به صورت دستی و نامحدود تنظیم کنند.

<Callout type="info">
  نسخه‌های میزبانی شخصی می‌توانند بدون نیاز به Stripe، سقف دسترسی نامحدود برای کاربران و فضای دیسک تعیین کنند.
</Callout>
