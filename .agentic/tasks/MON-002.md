# MON-002 — Implement canonical exact-money operations

## Objective and implementation scope

Introduce exact minor-unit money types, currency metadata and explicit operation-specific rounding. Keep documented deprecated compatibility wrappers while banning new use. Handle negative amounts, zero, bounds and currencies with 0/2/3 minor units.
