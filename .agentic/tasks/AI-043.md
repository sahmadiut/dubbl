# AI-043 - Add explicit scoped approval and rejection decisions

## Objective and implementation scope

Decisions alone must not dispatch unqualified sensitive operations; AI-044 supplies execution integration.

## Inputs

- [Owner requirements](../sources/SOURCE.md#ai-agent-and-administration-owner-extension).

## Acceptance criteria

- [x] Expose shared REST/MCP explicit approve/reject operations bound to the actor, organization, exact persisted action/batch selection, resource versions, expiry and request idempotency key.
- [x] Reject model self-approval, clarification text, blanket confirmation, hidden policy changes, revoked credentials/permissions and stale/edited/expired proposals. Preserve existing business approvals and explain permitted next actors without disclosing unauthorized identities.
- [x] Persist atomic replay-safe decisions; concurrency and double submission return stable receipts without multiple queue transitions. Rejection/cancellation invalidates dependent actions and preserves completed effects.
- [x] Verify real REST/MCP/SQL race, lost acknowledgement, stale resource, denied approver, edited selection, expiry, replay, cancellation and dependency rejection cases.
