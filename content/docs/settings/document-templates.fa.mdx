قالب‌های سند نحوه نمایش فاکتورها، پیش‌فاکتورها و سایر اسناد PDF شما را کنترل می‌کنند. به مسیر **تنظیمات > قالب‌ها** (**Settings > Templates**) بروید.

## ایجاد قالب

۱. روی **قالب جدید** (**New Template**) کلیک کنید
۲. نامی وارد کرده و نوع سند را انتخاب کنید
۳. تنظیمات زیر را پیکربندی کنید
۴. روی **ایجاد** (**Create**) کلیک کنید

می‌توانید برای هر نوع سند، یک قالب را به عنوان **پیش‌فرض** تعیین کنید. قالب پیش‌فرض هنگام تولید PDF به‌طور خودکار اعمال می‌شود.

## تنظیمات قالب

| فیلد | توضیحات |
|-------|-------------|
| نام (Name) | برچسبی برای این قالب (مانند «فاکتور استاندارد») |
| نوع (Type) | فاکتور، پیش‌فاکتور، رسید، فیش حقوقی یا سفارش خرید |
| رنگ شاخص (Accent Color) | رنگ مورد استفاده برای نوار بالای فایل‌های PDF |
| نشانی اینترنتی لوگو (Logo URL) | آدرس اینترنتی تصویر لوگوی شما (در پیش‌نمایش HTML نمایش داده می‌شود) |
| نمایش تفکیک مالیات (Show Tax Breakdown) | نمایش یا عدم نمایش مبالغ مالیات در بخش جمع کل |
| نمایش شرایط پرداخت (Show Payment Terms) | نمایش یا عدم نمایش تاریخ «سررسید تا» در زیر جمع کل |
| تنظیم به‌عنوان پیش‌فرض (Set as Default) | استفاده خودکار از این قالب برای نوع سند انتخاب‌شده |

## فیلدهای محتوا

این فیلدها به شما امکان می‌دهند محتوای سفارشی را به اسناد خود اضافه کنید. همه فیلدها از **متغیرهای قالب** پشتیبانی می‌کنند.

### اطلاعات بانکی

اطلاعات بانکی خود را اضافه کنید تا مشتریان بدانند مبلغ را به کجا پرداخت کنند. این اطلاعات به عنوان بخشی مجزا در فاکتور نمایش داده می‌شود.

```
IBAN: DE89 3704 0044 0532 0130 00
SWIFT/BIC: COBADEFFXXX
Bank: Commerzbank
```

### دستورالعمل‌های پرداخت

دستورالعمل‌های متنی آزاد درباره نحوه پرداخت. این بخش به صورت مجزا در زیر اطلاعات بانکی نمایش داده می‌شود.

```
لطفاً هنگام پرداخت، شماره فاکتور {{invoiceNumber}} را قید فرمایید.
فقط حواله بانکی، چک پذیرفته نمی‌شود.
```

### یادداشت‌ها

یادداشت‌های پیش‌فرضی که به انتهای هر سند تولیدشده با این قالب اضافه می‌شوند. فاکتورهای مجزا نیز می‌توانند یادداشت‌های اختصاصی خود را داشته باشند؛ در صورت وجود هر دو، یادداشت‌های قالب اولویت دارند.

```
از همکاری شما سپاسگزاریم. پرداخت‌های معوق مشمول ۱.۵٪ جریمه ماهانه خواهند شد.
```

### سربرگ HTML

کد HTML سفارشی که در بالاترین قسمت سند، پیش از عنوان فاکتور نمایش داده می‌شود. برای درج برندینگ اضافی یا متن‌های حقوقی مفید است.

### پاورقی HTML

کد HTML سفارشی که در انتهای سند، پس از تمام بخش‌های محتوا رندر می‌شود. برای شرایط و ضوابط یا سلب مسئولیت‌های حقوقی کاربرد دارد.

## متغیرهای قالب

از این متغیرهای جایگزین در هر یک از فیلدهای محتوا استفاده کنید. هنگام تولید سند، مقادیر واقعی جایگزین آن‌ها خواهند شد.

| متغیر | توضیحات |
|----------|-------------|
| `{{orgName}}` | نام سازمان شما |
| `{{orgAddress}}` | نشانی سازمان |
| `{{orgTaxId}}` | شناسه مالیاتی / شماره ارزش افزوده سازمان |
| `{{orgPhone}}` | شماره تلفن سازمان |
| `{{orgEmail}}` | ایمیل سازمان |
| `{{orgRegistrationNumber}}` | شماره ثبت کسب‌وکار |
| `{{invoiceNumber}}` | شماره فاکتور (مانند INV-00001) |
| `{{issueDate}}` | تاریخ صدور |
| `{{dueDate}}` | تاریخ سررسید |
| `{{contactName}}` | نام مشتری |
| `{{contactEmail}}` | ایمیل مشتری |
| `{{contactAddress}}` | نشانی صورت‌حساب مشتری |
| `{{contactTaxNumber}}` | شماره مالیاتی / ارزش افزوده مشتری |
| `{{reference}}` | ارجاع فاکتور / شماره سفارش خرید (PO) |
| `{{subtotal}}` | جمع جزء قالب‌بندی‌شده |
| `{{taxTotal}}` | مبلغ مالیات قالب‌بندی‌شده |
| `{{total}}` | مبلغ کل قالب‌بندی‌شده |
| `{{currency}}` | کد ارز (مانند USD، EUR) |

## پیش‌نمایش

از منوی قالب روی گزینه **Preview** کلیک کنید تا ببینید یک فاکتور نمونه با تنظیمات شما چگونه نمایش داده می‌شود. همچنین می‌توانید از طریق پنجره پیش‌نمایش، روی **Download Sample PDF** کلیک کنید تا خروجی واقعی PDF را بررسی نمایید.

## چیدمان PDF

فایل PDF تولیدشده از یک طراحی ساده، تمیز و مینیمال پیروی می‌کند:

1. **نوار شاخص رنگی (Accent bar)** - یک نوار رنگی ۴ پیکسلی در بالای صفحه
2. **عنوان فاکتور** - عبارت "Invoice" (یا برای استرالیا و نیوزیلند: "Tax Invoice")
3. **فراداده (Metadata)** - شماره فاکتور، تاریخ صدور، تاریخ سررسید
4. **فروشنده / صورت‌حساب به (Seller / Bill to)** - چیدمان دو ستونه با مشخصات سازمان و مشتری
5. **خلاصه سررسید** - متنی با فونت درشت: "X$ سررسید در YYYY-MM-DD"
6. **اقلام فاکتور** - جدولی شامل شرح، تعداد، قیمت واحد، مبلغ کل ردیف
7. **جمع‌های کل** - راست‌چین‌شده: جمع جزء (Subtotal)، مالیات، مجموع کل، مبلغ پرداخت‌شده، مبلغ قابل پرداخت
8. **محتوای تکمیلی** - اطلاعات بانکی، دستورالعمل‌های پرداخت، یادداشت‌ها
9. **پاورقی** - شماره فاکتور و مبلغ قابل پرداخت، همراه با نشان تجاری dubbl

## رفتارهای وابسته به کشور

فاکتور به‌طور خودکار بر اساس تنظیمات کشورِ سازمان شما تطبیق پیدا می‌کند.

### برچسب‌های شناسه مالیاتی

| کشور | برچسب مورداستفاده |
|---------|-----------|
| اتحادیه اروپا / بریتانیا | VAT |
| استرالیا | ABN |
| نیوزیلند | GST |
| کانادا | GST/HST |
| سایر کشورها | Tax ID |

### عنوان فاکتور

برای سازمان‌های مستقر در استرالیا و نیوزیلند که شناسه مالیاتی ثبت کرده‌اند، عنوان فاکتور از "Invoice" به "Tax Invoice" تغییر می‌یابد.

## هشدارهای انطباق قانونی

هنگام مشاهده فاکتور، ممکن است هشدارهای انطباق قانونی را بر اساس کشور سازمان خود مشاهده کنید. این موارد اطلاعات ناقصی را مشخص می‌کنند که ممکن است از نظر قانونی الزامی باشند.

| کشور | فیلدهای الزامی | شدت |
|---------|----------------|----------|
| کشورهای اتحادیه اروپا | نشانی سازمان، شماره VAT | Error |
| بریتانیا | نشانی سازمان، شماره VAT | Error |
| استرالیا | شماره ABN | Warning |
| نیوزیلند | شماره GST | Warning |
| کانادا | شماره GST/HST | Warning |
| سایر کشورها | نشانی سازمان، شناسه مالیاتی (Tax ID) | Warning |

برای فاکتورهای B2B در اتحادیه اروپا (زمانی که مخاطب دارای شماره مالیاتی باشد)، ثبت نشانی مخاطب نیز توصیه می‌شود.

هشدارهای انطباق صرفاً جنبه اطلاع‌رسانی دارند و مانع از صدور فاکتور نمی‌شوند. می‌توانید وضعیت انطباق را از روش‌های زیر بررسی کنید:

- صفحه جزئیات فاکتور (بنر هشدار در بالای صفحه)
- از طریق API: مسیر `GET /api/v1/invoices/{id}/compliance`
- از طریق MCP: ابزار `check_invoice_compliance`

## API

| اندپوینت | متد | توضیحات |
|----------|--------|-------------|
| `/api/v1/document-templates` | GET | فهرست قالب‌ها |
| `/api/v1/document-templates` | POST | ایجاد قالب |
| `/api/v1/document-templates/{id}` | PATCH | به‌روزرسانی قالب |
| `/api/v1/document-templates/{id}` | DELETE | حذف قالب |
| `/api/v1/document-templates/{id}/preview` | POST | پیش‌نمایش به‌صورت HTML |
| `/api/v1/document-templates/{id}/preview?format=pdf` | POST | دانلود نمونه PDF |
