کلیدهای API امکان تعامل نرم‌افزارهای خارجی با سازمان دابل شما را از طریق REST API فراهم می‌آورند. برای مدیریت آن‌ها به منوی **تنظیمات > کلیدهای API** بروید.

## ساخت کلید API جدید

۱. روی **کلید API جدید** کلیک کنید
۲. یک نام توصیفی مشخص نمایید (مثلاً "Zapier Integration" یا "سیستم انبارداری")
۳. کلید تولیدشده تنها یک‌بار نمایش داده می‌شود - آن را فوراً کپی و در محلی امن ذخیره کنید
۴. پس از بستن پنجره، متن کلید دیگر قابل مشاهده نخواهد بود

## مدیریت کلیدها

| فیلد | شرح |
|---|---|
| نام | عنوان توصیفی کلید |
| تاریخ ایجاد | زمان ساخت کلید |
| آخرین استفاده | آخرین باری که درخواستی با این کلید ارسال شده |
| وضعیت | فعال (Active) یا ابطال‌شده (Revoked) |

## ابطال کلید (Revoke)

در صورت به خطر افتادن امنیت کلید یا عدم نیاز به آن:

۱. کلید مورد نظر را در فهرست بیابید
۲. روی گزینه **ابطال (Revoke)** کلیک کنید
۳. دسترسی کلید بلافاصله مسدود و متوقف خواهد شد

## نکات امنیتی مهم

- برای هر سامانه یا افزونه مجزا، کلید اختصاصی بسازید
- کلیدهای بلااستفاده را بی‌درنگ ابطال نمایید
- هرگز کلیدهای API را در گیت، مخازن عمومی یا لاگ‌های سمت کلاینت قرار ندهید
- کلیدهای دسترسی را به صورت دوره‌ای بازتولید (Rotate) فرمایید

## استفاده از API

برای مطالعه راهنما و فهرست کامل اندپوینت‌های قابل دسترس، به [مرجع API](/docs/api-reference) مراجعه فرمایید.
