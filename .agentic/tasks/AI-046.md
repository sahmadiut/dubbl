# AI-046 - Add trusted sensitive domain preview adapters and business-policy evaluation

## Objective and implementation scope

Expand AI-045 without enabling sensitive dispatch. AI-042 independently integrates both children; AI-043 decisions and AI-044 approved execution remain separate gates.

## Inputs

[AI-042](AI-042.md), [AI-008](AI-008.md), [preview contract](../docs/AI_ACTION_PREVIEWS.md), [product experience](../docs/AI_PRODUCT_EXPERIENCE.md), and [owner requirements](../sources/SOURCE.md#ai-agent-and-administration-owner-extension).

## Acceptance criteria

- [x] Review actual shared domain operations and document a finite supported posting/payment/deletion/external-sending set with exact strict arguments and current permissions. Unsupported variants, Stripe and credential/security/provider/role operations remain unavailable.
- [x] Supply domain-derived complete structured effects, target and before/after values, exact separate currency amounts, recipients, dates/FX and irreversible effects for each supported adapter; never synthesize a preview from model narration or raw arguments alone.
- [x] Evaluate current business-approval conditions through existing policy; bind policy/resource snapshots and report permitted next actors without disclosing unauthorized identities. Approval metadata cannot substitute for valid approval of revised resources or permit self-approval.
- [x] Integrate every adapter with AI-045 persisted versioned proposals, selected dependency closure, safe revision, stale detection and live disclosure/retention checks. Preview never performs business mutations, external delivery or approval.
- [x] Verify real REST/MCP and disposable SQL scenarios for each supported action, financial/currency/reference/period gates, scope, stale/edited resources or policy, unsafe recipients, bounded display and no-effect behavior.

## Verification

Focused actual REST/MCP/SQL disposable-loopback checks, typecheck/lint, schema/migration and capability/coverage checks, controller/diff checks. No full build, dev server or live-provider claim.

posting, USD invoice cash, EUR bill cash into USD GL, manual draft deletion and

historical approved metadata, exact separate currencies, dependency selection,

existing rows remain unchanged. Batch documentation now describes the actual
mixed schemas, per-action grants, version compatibility and GL impact totals.

Four actual integration suites and 14 unit tests pass, along with typecheck,
scoped lint, schema/capability/coverage/legacy/controller/diff checks. Full lint
has no errors and retains existing warnings; the observed unused test import
was resolved by final prepared-step assertions. Money inventory has exactly
the same 1447 baseline failures and zero new errors. See
[attempt](../evidence/AI-046-attempt-1.md), [self-review](../evidence/AI-046-review-1.md)
