# AI-011 - Build scoped AI usage and operations dashboard

## Objective and implementation scope

Provide usage analytics and run monitoring within existing admin navigation.

This task implements the owner-requested AI feature; it does not authorize deployment or relax existing financial/release gates.

## Inputs

- [Product experience contract](../docs/AI_PRODUCT_EXPERIENCE.md): normative journeys, UI states and observable UX acceptance.
- [Owner requirements](../sources/SOURCE.md#ai-agent-and-administration-owner-extension).
- [Architecture and delivery plan](../docs/AI_AGENT_PLAN.md).
- Actual source and dependency evidence; verify current contracts before editing.

## Acceptance criteria

- [x] Show token categories, estimated cost by currency, requests, tool calls, success/failure, latency, active runs and quota remaining with date/user/organization/provider/model filters and scoped export.
- [x] Users see their own permitted usage, organization managers see authorized organization totals, and site administrators see authorized aggregate usage; transcript audit access is a separate permission.
- [x] Authorized administrators configure per-user/organization limits, inspect redacted errors and cancel runs or disable execution; UI and REST/MCP policy controls agree.
- [x] Test empty states, missing provider usage, accurate paginated totals, exact cost display, English/Persian RTL behavior and unauthorized drill-down/export.

- [x] Organize My usage, permitted organization totals and site-only aggregates as separate views. Implement missing scoped filters, pagination, exports and site-session services with corresponding MCP operations before advertising them; never use organization credentials for global access or infer totals from one page.
- [x] Show observed, reserved and unknown usage separately, estimated cost per billing currency, price version, period and UTC reset translated to the user's timezone. Provide limit explanations and useful next actions for zero/missing budget, unavailable price and exhausted quota; unknown is not zero and zero is not unlimited.
- [x] Add authorized immutable price-version forms and organization/member budget forms over AI-005 services. Explain exact major billing-currency rates per million tokens, decimal precision, monthly/per-run/rate/concurrency limits and the requirement for both budgets before a connection test. Never auto-fetch/invent rates, reset usage on edit or silently convert billing currencies.
- [x] Support filter reset, loading/empty/error states, sanitized actionable run details, safe stop/disable confirmations, inline validation and version conflicts. Test role-specific interactions, preserved non-secret edits, delayed org-switch responses, paginated/export totals and large exact values in both locales.
