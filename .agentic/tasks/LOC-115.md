# LOC-115 - Localize currency unit names across website pages

## Objective and implementation scope

When the active application language is fa-IR, display Persian currency unit
names throughout website pages. In particular, the owner requires the visible
IRR unit to read "ریال", instead of using IRR as its primary display label.
Switching to English must retain existing English presentation.

Provide a shared locale-aware currency-label adapter/catalog and adopt it in
CurrencySelect (including compact mode and search), CurrencyInput prefixes,
amount formatters, table cells, badges, totals, summaries, report headings and
other visible currency-unit labels across dashboard and public website pages.
Inspect actual callers rather than replacing source strings globally. Cover
other supported currencies with Persian names and document a deterministic safe
fallback for unknown/unmapped codes. Currency code fields explicitly intended
to show ISO identifiers remain technical fields and must be inventoried as
exceptions; normal money/unit labels must use the localized presentation.

The active language determines the name independently of numeral preference,
currency selection and calendar. Keep canonical ISO values such as IRR/USD in
state, select values/callbacks, URLs, storage, REST/MCP payloads and machine
exports. Do not rename database/reference currency rows or saved user content.
Do not change minor-unit scales, rounding, grouping, signs, exact arithmetic,
FX, currency-history guards or the existing fixed-two payroll/legacy contracts.
This task introduces no new business operation or endpoint; existing MCP
operations retain canonical codes and their current shared services.

Website presentation is the scope. Existing issued document snapshots and
machine CSV/JSON exports remain unchanged; email/PDF output localization stays
with its existing tasks. Preserve Stripe under DEC-008. No rial/toman conversion
or production IRR activation is authorized. Other Persian currency terminology
remains subject to the existing native review, while "ریال" is owner-specified.
