# RTL-007 - Qualify self-hosted Persian typography and font notices

## Objective and implementation scope

Inspect actual Next font delivery and bundled assets; self-host the approved Persian font with existing owner-approved provenance/license notice scope preserved. Verify tabular numeral typography, fallback behavior and no runtime CDN requirement. Preserve user font preference contracts and existing private font assets; do not infer redistribution rights or alter frozen provider UI. Record font and text-spacing foundation evidence; module adoption and parent visual/layout qualification remain independent.

## Inputs

- Parent [RTL-002](RTL-002.md), [requirements](../sources/SOURCE.md#rtl-uiux-strategy) and prior RTL-001 evidence.
- Actual fork source and installed framework behavior. DEC-005 excludes screenshot requirements, not behavioral/layout/accessibility review. DEC-008 freezes Stripe/provider work.

## Acceptance criteria

- [x] Approved Persian font is locally delivered with the required applicable license notice and user-selected fallback contracts remain preserved.
- [x] Tabular numeral and mixed-script fallback typography are explicitly tested without rescaling or localizing machine values.
- [x] Existing English/Persian presentation combinations and task-appropriate static/catalog/controller checks pass; unrun browser/font/layout review is explicit.

## Verification

Use real controls/components, exact callback/value assertions, appropriate CSS/runtime checks and focused regressions. Record exact commands/results/context and limits. No full build/dev startup or application DB writes. Existing REST/MCP values remain canonical; no new operation is introduced.

notice; existing private assets, font choices and mixed-script fallback are
preserved. Actual Next loader, default-instance font shaping, compiled typography
and real controls across 24 presentation/font choices are verified. No mounted
font visibility, native, module/output, PDF, mobile/zoom or text-spacing
qualification is claimed. RTL-008 is next; this child does not complete parent
