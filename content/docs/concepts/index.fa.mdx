---
title: مفاهیم حسابداری
description: با اصول بنیادین حسابداری که دابل بر پایه آن‌ها ساخته شده است آشنا شوید.
---

import { Cards, Card } from "fumadocs-ui/components/card";
import { Callout } from "fumadocs-ui/components/callout";

شناخت چند مفهوم کلیدی در حسابداری به شما کمک می‌کند بیشترین بهره را از دابل (Dubbl) ببرید. چه یک حسابدار باتجربه باشید و چه کارآفرینی انفرادی که برای نخستین بار امور مالی‌اش را پیگیری می‌کند، این صفحات اصول پشت پرده هر قابلیت را شرح می‌دهند.

<Callout type="info">
  در حسابداری تازه‌کار هستید؟ برای یک مقدمه ساده و متناسب با مبتدیان، از [حسابداری برای کارآفرینان انفرادی](/docs/concepts/for-solopreneurs) شروع کنید.
</Callout>
