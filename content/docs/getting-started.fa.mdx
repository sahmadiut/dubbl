## پیش‌نیازها

- **Node.js** نسخه ۲۰ به بالا و npm
- **PostgreSQL** نسخه ۱۵ به بالا (یا استفاده از Docker)
- **فضای ذخیره‌سازی سازگار با S3** (اختیاری، برای آپلود فایل‌ها)

## نصب

```bash
git clone https://github.com/dubbl-org/dubbl.git
cd dubbl
pnpm install
```

## متغیرهای محیطی

```bash
cp .env.example .env
```

فایل `.env` را با مقادیر پیکربندی خود ویرایش کنید:

```bash title=".env"
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/dubbl

# Auth
AUTH_SECRET=your-random-secret-here
AUTH_URL=http://localhost:3000

# Stripe (optional)
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# S3 Storage (optional)
S3_BUCKET=dubbl-uploads
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=...
S3_SECRET_ACCESS_KEY=...
S3_ENDPOINT=https://s3.amazonaws.com
```

## شروع محیط توسعه

```bash
pnpm dev
```

نشانی [http://localhost:3000](http://localhost:3000) را در مرورگر خود باز کنید.

<Callout type="info">
  اگر اسکریپت seed را اجرا کرده‌اید، با اطلاعات کاربری **demo@dubbl.dev** / **password123** وارد شوید. این کار دسترسی به یک سازمان نمایشی با داده‌های کامل از جمله سرفصل حساب‌ها، مخاطبان، فاکتورهای فروش، صورت‌حساب‌های خرید، حساب‌های بانکی، پروژه‌ها و موارد دیگر را در اختیارتان قرار می‌دهد.
</Callout>
