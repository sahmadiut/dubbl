# Vazirmatn 33.003

`Vazirmatn-Variable.woff2` is the unmodified, combined Persian/Arabic/Latin
variable font from the approved Vazirmatn project. It includes weight axis
100–900. Dubbl loads it through `next/font/local`; no request to a font CDN
or Google font stylesheet is needed for this font at build or runtime.
