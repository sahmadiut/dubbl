# MON-040 - Adopt exact invoice lifecycle contracts

## Objective and implementation scope

Invoice send/void/write-off/interest and approval lifecycle and corresponding MCP. Retain posting, audit, period locks, saved FX and safe preflight. Settlement coordinates with MON-021; public/payment-link/signing/PDF remains MON-016.

## Inputs

Parent [MON-019](MON-019.md), MON-011 evidence, ADR-006, MONEY_MANIFEST and actual source. Requirements: [migration](../sources/SOURCE.md#database-and-currency-migration) and [API compatibility](../sources/SOURCE.md#api-backward-compatibility).

## Acceptance criteria

- [x] Every boundary in this slice has documented inputs, outputs, units, exact aliases and supported ranges.
- [x] Actual REST/MCP fixtures cover legacy and exact clients, authorization and organization isolation.
- [x] Invalid or unsupported values fail before mutation; responses preserve numeric compatibility without bigint crashes or silent precision/unit loss.

## Verification

Run meaningful operation fixtures, typecheck and lint. No builds or unrequested dev server.

## Handoff

Implemented shared `lib/api/invoice-lifecycle.ts`, exact boundary arithmetic and
bounded invoice stock/FIFO services. Eight REST invoice operations, nine new/
adopted MCP tools and generic approval-request actions share scoped preflight,
permissions/locks and atomic posting/status/stock/number/request/action changes.
Numeric money retains additive exact strings; interest-major and recovery-minor
aliases preserve their distinct units. Saved FX and original new stock/COGS values
survive rate/cost changes; unsafe values fail without committed mutations.
See `../registries/INVOICE_LIFECYCLE_WIRE_CONTRACTS.md` and attempt/review evidence
for real REST/SDK/PostgreSQL fixtures, currency/scoping/rollback/concurrency checks.
No schema/migration/configured database/IRR flag/dev/build/deployment changes.
Legacy unlinked stock/FX, optional email/PDF/provider delivery, external writer/
configuration races, full-domain/settlement/reporting and financial qualification
retain their assigned gates. Next task is MON-041 exact quote contracts.
